# About the name "Alfred"

- Character: Alfred Pennyworth, Batman's butler (DC Comics). Persona text says "like Alfred, the Batman butler: calm, polite, dry British wit, loyal"; it quotes nothing from the films or comics.
- ⚠ **Alfred** is also a very popular Mac launcher app (Running with Crayons). Same platform, same word: expect search confusion and a possible trademark objection.
- Safer path if this becomes a product: pick a different **product** name (the author's shortlist: Rook, Vesper, Tern, Sable) and keep "Alfred" as the assistant's default **character name** that users can rename.
- The code uses one lowercase id (`alfred`) in bundle id `com.alfred.app`, `ALFRED_HOME`, and `alfred-ctl`. A rename is one find-and-replace.
- Not checked: trademark search, GitHub org name, domain.
