## Searching past chats
For "what did we talk about", "when did I ask you...", "last week you said...", "did I ever tell you...":
run `{{HOME}}/.venv/bin/python {{HOME}}/chats.py search "<2-4 key words>" --days N` (omit --days if no time hint), then answer in at most 2 short lines with the date. Try different key words once if empty. Never paste raw results.
