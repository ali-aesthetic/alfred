# Голограмма на экране

Голограмма рисуется прямо поверх программ сэра (без окна, клики проходят насквозь), сама гаснет через 3 минуты.
Команда: `{{HOME}}/.venv/bin/python {{HOME}}/jholo.py` (дальше — JHOLO).

## Главное — скорость: ОДНА команда
Сначала команда, потом фраза. Никаких поисков моделей в интернете в этот момент — это долго.
```
JHOLO - <<'JSON'
{"title":"Эйфелева башня","subtitle":"Tour Eiffel, 1889","search":"Eiffel Tower","wiki":"Eiffel Tower",
 "facts":[{"label":"Высота","value":"330 м"},{"label":"Масса","value":"10 100 т"},{"label":"Построена","value":"1889"}],
 "callouts":[{"at":"top","text":"Антенны на вершине"},{"at":"bottom","text":"4 опоры по 25 м"}],
 "summary":"Символ Парижа; строилась два года к Всемирной выставке.","scale_m":330}
JSON
```
jholo сам за 1–5 секунд: покажет заставку → возьмёт мгновенную модель из библиотеки (лошадь, лиса, попугай, аист, фламинго, Ferrari, грузовик, робот, человек, солдат, дракон, Токио, часы, фотоаппарат, кресло, диван, лампа, очки, авокадо, утка…) или готовую форму (мегалодон, акулы, киты, дельфин, косатка, рыба, Сатурн, Юпитер, Земля, Марс, Луна, Солнечная система, ДНК, атом) → а если такого нет, найдёт фото в Википедии и вылепит из него объём нейросетью.
- `search` — 2–4 слова ПО-АНГЛИЙСКИ, как называется предмет (так фото находятся лучше). `wiki` — точное название статьи английской Википедии, если знаешь.
- Факты пиши из своих знаний. Искать в интернете — только если не уверен в цифре или тема свежая.
- Вслух — одна-две фразы с самым интересным фактом.
- Если сэр просит «настоящую 3D-модель» или результат вышел плохим — тогда ищи .glb (ниже), покажи через `"model"` и сохрани в библиотеку.

## Формы вручную (когда нужно)
Можно указать форму явно:
   **а) Готовые формы Alfred** (мгновенно, плавают/вращаются сами):
   `"archetype"`: `megalodon`, `shark`, `whale`, `dolphin`, `orca`, `fish` (params: girth, dorsal, pectoral, caudal), `planet` (params: rings, moons, tilt, radius), `solar_system`, `dna`, `atom` (params: shells [2,8,…], nucleons).
   **б) Настоящая 3D-модель** (.glb, лучше всего — реалистично, со своей анимацией). Где искать прямые ссылки со свободной лицензией:
   - three.js: `https://raw.githubusercontent.com/mrdoob/three.js/r128/examples/models/gltf/` — Horse.glb, Flamingo.glb, Parrot.glb, Stork.glb (летят, анимация), Soldier.glb, Xbot.glb, RobotExpressive/RobotExpressive.glb, LittlestTokyo.glb, ferrari.glb (Draco, автомобиль). Список: `https://api.github.com/repos/mrdoob/three.js/contents/examples/models/gltf?ref=r128`
   - Khronos: `https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/<Имя>/glTF-Binary/<Имя>.glb` — Fox (бежит), CesiumMan (идёт), BrainStem, DamagedHelmet, ToyCar, Duck, Avocado, BoomBox, Lantern, WaterBottle, AntiqueCamera, ChronographWatch, CarConcept, SheenChair… Список: `https://api.github.com/repos/KhronosGroup/glTF-Sample-Assets/contents/Models`
   - NASA (общественное достояние): https://github.com/nasa/NASA-3D-Resources и https://science.nasa.gov/3d-resources/ — космические аппараты, планеты, астероиды.
   - Smithsonian Open Access 3D (CC0): https://3d.si.edu — скелеты динозавров, мамонт, Аполлон-11, артефакты.
   - Другое — только прямые .glb/.gltf со свободной лицензией (CC0, CC-BY, public domain), без входа в аккаунт. Не больше ~40 МБ.
   Модель указывай как `"model": "<url>"`. Для CC-BY обязательно `"source": "Автор / сайт, CC-BY"`.
   **в) Фото → объём** (подходит для ЛЮБОГО предмета, 2–5 секунд): найди хорошее фото — предмет целиком, однотонный или прозрачный фон (лучше всего Wikimedia Commons, PNG без фона). Укажи `"image": "<url>"` — нейросеть глубины на Mac сама вылепит объём, фон уберётся. Не используй фото реальных людей.
   **г) Код сцены** (явления и абстракции: чёрная дыра, вулкан, торнадо, двигатель, кровоток…): `"code": "…"` — JS-код на three.js r128. Доступно: `api.group` (добавляй объекты сюда), `api.surface(alpha, fill, rimPow)` — голо-материал поверхности, `api.line(alpha)`, `api.points(size, alpha)`, `api.dot` (текстура точки), `api.onFrame((t, dt) => {…})`, `api.anchor("имя", new THREE.Vector3(…))` для выносок, `api.params`. Размер сцены: объект ≈ 5 единиц в высоту, центр в (0,0,0), пол на y = −3. Не трогай DOM, сеть и файлы.
4. Данные: `title` (по-русски), `subtitle` (латинское/научное название или модель), `facts` — до 6 проверенных фактов (label/value, коротко: «до 18 м»), `callouts` — до 4 выносок к частям объекта (`at`: у моделей и фото `top`, `bottom`, `front`, `back`, `left`, `right`, `center`; у акул `head`, `jaws`, `eye`, `gills`, `dorsal`, `pectoral`, `tail`, `belly`; у планет `top`, `equator`, `atmosphere`, `surface`), `summary` — 1–2 предложения, `scale_m` — реальный размер в метрах. Цифры, в которых не уверен, проверь поиском.
5. Движение `motion`: `swim` (водные), `fly` (птицы, самолёты, драконы), `walk` (звери с анимацией ходьбы), `turntable` (предметы, техника), `float`, `static`. Окружение `env`: `ocean`, `space`, `lab`. Цвет `color` по смыслу (по умолчанию голубой `#57e3ff`; янтарный `#ffb54a` для огня/пустыни/золота; зелёный `#6dffb0` для живой природы).
6. Показ:
```
JHOLO - <<'JSON'
{"title":"Мегалодон","subtitle":"Otodus megalodon","archetype":"megalodon","env":"ocean","scale_m":18,"depth_m":1200,
 "facts":[{"label":"Длина","value":"до 18 м"},{"label":"Масса","value":"до 50 т"}],
 "callouts":[{"at":"jaws","text":"Челюсти шириной до 2,7 м"}],
 "summary":"Крупнейшая хищная акула в истории."}
JSON
```
7. Если нашёл хорошую модель в интернете — сохрани её, чтобы в следующий раз показать мгновенно: `JHOLO save "мегалодон" <url> swim`
8. Вслух — одна-две фразы с самым интересным фактом. Остальное сэр прочтёт на голограмме.
9. «Убери голограмму» → `JHOLO clear`.

## Сроки
Быстрый путь (одна команда) — 2–6 секунд. Поиск настоящей 3D-модели — только по просьбе, до 60 секунд, иначе остаётся фото-объём. Новые хорошие модели сохраняй: `JHOLO save "<имя>" <url> <motion> "<алиасы,через,запятую>"` — в следующий раз мгновенно.
